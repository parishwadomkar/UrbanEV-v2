# Source attribution

UrbanEV-Opti incorporates code from:

- [UrbanEV-v2, VIPVmain](https://github.com/parishwadomkar/UrbanEV-v2/tree/VIPVmain/src/main/python/Opti).
- [Large-scale-LBBD-Optimization](https://github.com/parishwadomkar/Large-scale-LBBD-Optimization).

Modifications adapt the planning workflows to seasonal VIPV demand, shared input validation, annual site decomposition, solver controls, result accounting, and comparisons. Source references are retained in `SOURCE_PROVENANCE.json`.

The Apache License 2.0 text accompanying the standalone LBBD code is retained in `LICENSE`. Existing source notices and the parent UrbanEV repository's license and notices remain applicable. Framework illustrations in `assets/Considerations.png` and `assets/LBBD.png` originate from the standalone LBBD repository.
